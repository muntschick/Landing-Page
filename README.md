# Landing-Page
Landing-Page, in den streamlit-secrets sind die Links sowie das Zugangspw festgelegt.  
.streamlit/secrets.toml sieht wie folgt aus:
```
[auth]
password = "given_password"

[[links]]
text = "Platzhaltertext 1"
url = "https://example.com/1"

[[links]]
text = "Platzhaltertext 2"
url = "https://example.com/2"

[[links]]
text = "Platzhaltertext 3"
url = "https://example.com/3"

[[links]]
text = "Platzhaltertext 4"
url = "https://example.com/4"

[[links]]
text = "Platzhaltertext 5"
url = "https://example.com/5"

[[links]]
text = "Platzhaltertext 6"
url = "https://example.com/6"
```
